Settings

先选择已有 track 或新建一个 track，再选择信息源并配置每个 source 的细节。

Tracks

选择一个已有 track 继续编辑，或者新建一个自定义 track。

Track Identity

这里决定保存后的 `tracks/<id>.yaml` 文件名和报告里显示的名称。

Search and Output

这些 queries 会统一用于 arXiv、GitHub、Hacker News 和 X/Twitter；每个平台下面只保留平台特有配置。

Sources

先决定这个 track 从哪里收集信号。下面只会展开已选 source 的细节配置。

Source Details

每个已选 source 在这里填自己的抓取范围。没选的 source 会自动收起。

arXiv

Hugging Face papers

使用下面的关键词筛选 Hugging Face 每日论文；这里不需要额外账号列表。

RSS blogs

GitHub

GitHub 会使用统一的 track search queries；这里不需要单独填写搜索词。

Hacker News

Hacker News 也会使用统一的 track search queries。

Reddit

X/Twitter

X/Twitter 的关键词搜索也来自统一的 track search queries；勾选“只看这些账号”后，会只看上面的 accounts。

小红书

每行一个博主：名称 | profile 链接。小红书需要运行环境登录 OpenCLI；没有登录时会跳过，不影响其他 source。

知乎

每行一个作者：名称 | profile 链接。知乎会同时抓文章和回答，再用统一 track search queries 做筛选。
