Codex Radar

场景: 发现与雷达

围绕 Codex 生态的资源和动态雷达，适合快速了解工具、案例和社区更新。

适合什么时候用
想跟进 Codex 周边工具、教程、生态变化时，把它作为一个入口页。
本周推荐理由
适合作为工具雷达的参考样例：垂直、轻量、信息密度高，也能帮助我们观察 Codex 生态里哪些工具正在冒头。

OpenCLI

场景: 自动化连接

把浏览器连接给本地 agent 的自动化桥，适合需要登录态页面抓取或操作的场景。

适合什么时候用
跑小红书、知乎这类需要浏览器登录态的 source，或者让 agent 操作网页。
本周推荐理由
对 OmniSource 这种多平台信息源很关键：当内容需要登录态或没有稳定 API 时，它能把浏览器变成可控 source。

Aider

场景: 编程开发

终端里的 AI 结对编程工具，强调直接读写代码、配合 git 修改。

适合什么时候用
适合希望在命令行里快速改代码、生成 patch、配合现有 repo 迭代的人。
本周推荐理由
仍然是理解命令行 AI 编程工作流的好入口，适合和 Codex、Claude Code 等工具做横向对比。

Continue

场景: 编程开发

开源 IDE AI 助手，支持把模型、上下文和团队规则配置进开发环境。

适合什么时候用
团队想把代码助手接进 VS Code / JetBrains，并保留自定义模型和规则时可以评估。
本周推荐理由
适合关注“团队如何把 AI 助手接入日常 IDE”的用户，配置空间比单点工具更大。

Dify

场景: 应用搭建

面向 agent、RAG 和工作流应用的可视化构建平台。

适合什么时候用
当你想快速把一个 AI workflow 做成可测试的应用，而不是只停留在脚本阶段。
本周推荐理由
代表了 agent / RAG / workflow 从脚本走向可交付应用的路线，适合想快速搭建原型的人试用。
